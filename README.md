# Ақылжан — открытые материалы

Ақылжан (aqylzhan.kz) — адаптивный тренажёр по математике и логике для 1–6 классов на казахском, русском и английском языках. В банке 23 841 задача по 34 темам, и сложность каждой уточняется по ответам учеников, а не назначается вручную раз и навсегда.

Это **публичная витрина** проекта: методология, инструменты и демо-данные. Сам сайт, полный банк задач и данные пользователей здесь не публикуются.

## Что здесь есть

| Папка | Содержимое |
|---|---|
| `docs/architecture.md` | Как устроена платформа: три роли, один бэкенд |
| `docs/methodology.md` | Как мы калибруем сложность, ищем дубли, классифицируем задачи по Блуму |
| `scripts/recalibrate_difficulty.py` | Пересчёт сложности задач: биномиальный тест + байесовское сглаживание |
| `scripts/find_duplicates.py` | Поиск дублей: точное совпадение и числовой «отпечаток» |
| `data/sample_questions.csv` | 25 демо-задач на трёх языках, с темой и уровнем по Блуму |

## Быстрый старт

Нужен только Python 3.9+, внешние библиотеки не нужны.

```bash
python scripts/recalibrate_difficulty.py --demo
python scripts/find_duplicates.py --demo
```

Со своими данными:

```bash
python scripts/recalibrate_difficulty.py attempts.csv
python scripts/find_duplicates.py questions.csv
```

Форматы файлов описаны в `docs/methodology.md`.
